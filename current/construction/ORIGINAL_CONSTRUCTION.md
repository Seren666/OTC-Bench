# Corrected single-slot input set

The portable generator is `code/generate_corrected.py`. Its nine path arguments are explicit: `--root`, `--sources`, `--package`, `--renderer`, `--geometry-helper`, `--targets`, `--donors`, `--human-selection`, and `--human-root`. The exact executed remote command is in `generation_process.json`. Add `--verify-only` to rerun the complete disk/source/human verification against an existing frozen output; generation refuses to overwrite `frozen_hashes.json`.

The root passed to the generator is the new experiment's `generated/` directory. Inference must use its `request_manifest.jsonl` and `frozen_hashes.json`, never the previous multi-slot manifest. Model condition values remain `N-near`; N request IDs use `__N__` to match the existing human-v2 identifiers. O/G/T/N all carry the actual external position; donor-check has no position and is shared across the four corresponding pair positions. Each target contributes 78 requests and 24 paired contrasts.

Rendering delegates to the byte-identical original renderer; the old geometry helper supplies only segmentation, scaled-R, position-slot and exchange checks. Every non-check disk image is rerendered directly from original sources and compared in full, then verified against the original marked scene outside current R/P/S. Every T/N pair swaps an identical donor block and equal-sized gray rectangle; G matches its own O plus only current R gray. Cross-position images naturally expose different background and must not be compared as if the background were fixed.

All original JPEGs are retained and SHA-verified. Local Pillow 12.0/JPEG 9 and remote Pillow 11.3/libjpeg-turbo differ in JPEG IDCT rounding, despite identical JPEG bytes. The first remote preflight detected this at the human RGB check and stopped before freezing or inference. The corrected generation therefore uses SHA-bound lossless RGB PNGs decoded directly from the original JPEGs on the human-stimulus platform. `sources/decoded_rgb_manifest.jsonl` records original JPEG SHA, lossless PNG SHA, raw RGB SHA, dimensions, library versions and operation. This cache is not made from any prior composite. The actual 72 human PNG file hashes and complete RGB/RGBA pixels are checked independently. Different lossless PNG compression may change file hashes without changing pixels; both file hashes are retained in the crosscheck.

`source_support_upload.tar` and `decoded_sources_upload.tar` are small source/support transfer archives only. No generated-image archive is created. The 8,112 model input PNGs stay remote. `code/sync_generated_inputs.py` downloads the metadata and audits, verifies downloaded files against the frozen hash ledger, and preserves remote image paths for the inference runner.

The failed first JPEG decode preflight is retained remotely under `preflight_jpeg_decode_mismatch/` and in `source_decode_diagnostic.json`; it is outside the final input root and is not eligible for inference. No prior model outputs or participant responses were consulted in corrected input generation.
