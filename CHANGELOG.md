# Changelog

## 0.1.0-rc1 — research preview

- Named OTC-Bench (Overlay–Target Confusion Benchmark); owner-designated public destinations are GitHub Seren666/OTC-Bench and Hugging Face MortalSnow/OTC-Bench.
- Adds repository links and a label-free Hugging Face model-input configuration. No inputs, predictions or scores changed during publication preparation.

- Consolidates 800 distinct targets, 1,600 donor pairs, 6,400 input records and 38,400 cached answers.
- Preserves old96, old204 and new500 provenance; exports neutral IDs and model-facing inputs without class labels.
- Adds exact RGB reconstruction verification, independent evaluation CLI, aggregate human votes, cohort/instance tables and quantitative figures.
- Preserves both historical scoring modes without alias edits. The CLI defaults to the previously used format-tolerant mode; the frozen mode is explicit and available.
- Documents the three microwave human-alias coverage gaps, recorded source-image licenses, historical model-revision limits and differentiated human-review coverage.
- Includes no source/transformed photos, raw human questionnaire files, personal timestamps, click coordinates or credentials.
- No model calls, sample substitutions, new stimuli, prompt variants or public publication occurred during release preparation.

The owner authorized public distribution on 2026-09-30. Authorship and a specific code/metadata reuse license remain to be recorded; no paper publication, DOI, or institutional approval is implied.
